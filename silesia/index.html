The Silesia Corpus (Deorowicz, 2003) is a standard benchmark for larger files: 12 real-world files, 211,938,580 bytes in total, covering English prose, HTML, source and executable tarballs, database dumps, medical images, a star catalogue, XML and a PDF. It stresses what Canterbury cannot: multi-megabyte inputs. Baselines run at their command-line defaults (gzip -6, zstd -3, xz -6, brotli -11, zpaq method 2); the extra columns run other well-known codecs at their strongest practical setting (lz4 -9, bzip2 -9, bzip3, zstd -19 --long=27, xz -9e, 7-Zip PPMd, zopfli), single-threaded. Lower % = better compression. C = compress ms, D = decompress ms. All MBFA roundtrips must pass for results to be valid.
