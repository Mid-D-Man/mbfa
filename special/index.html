⚠ MBFA WASM not built — in-browser MBFA compression is unavailable. Browser gzip results above are still shown for comparison.

To enable MBFA in-browser compression:
1. Add [lib] with crate-type = ["cdylib"] to Cargo.toml
2. Add wasm-bindgen exports to src/lib.rs:
   #[wasm_bindgen] pub fn compress_wasm(data: &[u8]) -> Vec<u8>
3. Run wasm-pack build --target web --out-dir pkg
4. Deploy pkg/mbfa.js and pkg/mbfa_bg.wasm to the gh-pages root
5. The import path ../mbfa.js on this page will find them automatically

Alternatively add a wasm-pack build step to the CI deploy job and copy pkg/ into the gh-pages worktree before committing.
