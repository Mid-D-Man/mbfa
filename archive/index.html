Archive benchmark tests MBFA's multi-file archiving against standard archive formats across five directory types: source code, prose text, JSON/CSV data, binary/media, and a mixed directory. A full-corpus test exercises block grouping across all file types together.

What's being measured: final archive size (lower % = better), compress time (C ms), decompress / extract time (D ms), and a full roundtrip verification — every extracted file is byte-diffed against its original. RT PASS means all files extracted exactly. Competing formats: MBFA, zip, tar.gz, tar.zst, tar.xz, tar.br.
